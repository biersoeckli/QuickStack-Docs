QuickStack can install and keep cluster components up to date. They are managed from **QuickStack Settings** → **Updates & Add-Ons** → **Cluster Add-ons** and are only visible to administrators.

<img src="/img/docs/admin/cluster-add-ons/cluster-add-ons-overview.png" alt="Cluster Add-ons cards" />

## Available add-ons

| Add-on | Purpose | 
|--------|---------|
| **Longhorn** | Distributed block storage across cluster nodes (the `longhorn` storage class) |
| **CertManager** | Automated TLS certificate issuance; enables HTTPS for apps in QuickStack |
