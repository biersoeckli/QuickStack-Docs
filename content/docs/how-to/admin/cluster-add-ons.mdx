QuickStack can install and keep cluster components up to date. They are managed from **Settings** → **Platform** → **Updates & Add-Ons** → **Cluster Add-ons** and are only visible to administrators.

Each add-on card shows its status, installed version, and the next available version. Depending on the add-on you can **Install**, **Update**, or **Remove** it. Updates show a warning with the items to check first (for example, recent backups before a Longhorn update). See [Updates & Maintenance](/docs/how-to/admin/updates-and-maintenance) for the workflow.

## Available add-ons

| Add-on | Purpose |
|--------|---------|
| **Longhorn** | Distributed block storage across cluster nodes (the `longhorn` storage class) |
| **CertManager** | Automated TLS certificate issuance; enables HTTPS for apps in QuickStack |
| **Kubernetes Agent Sandbox** | Installs the agent sandbox components so QuickStack can run [AI agents](/docs/how-to/agents) |
| **gVisor** | Provides an optional sandboxed runtime that Agent Sandboxes can select as their [Runtime Class](/docs/how-to/agents#runtime-isolation) |

<Callout type="warn">
**Canary-only add-ons**
The **Kubernetes Agent Sandbox** and **gVisor** add-ons are experimental and only appear when the **Canary Channel** is enabled under **Settings** → **Platform** → **Updates & Add-Ons**. See [Updates & Maintenance](/docs/how-to/admin/updates-and-maintenance#canary-channel).
</Callout>
